Archivos y formato esperado

Las fechas usan YYYY-MM-DD, los booleanos True/False y los importes son enteros. Las referencias entre archivos se validan como un conjunto; los detalles se incorporan dentro de cada venta.

Sincronización con Neo4j

Se ejecuta al importar. Usá este botón para completar una carga anterior o procesar cambios pendientes.

La primera carga requiere colecciones de negocio vacías. Si la base ya tiene esta misma carga, se verifica y reutiliza. Una fuente diferente requiere otra base; no se sobrescriben datos existentes. Neo4j se sincroniza al finalizar la importación; los pasos que fallen pueden reintentarse desde esta pantalla.
